# go-agent third-party licences

The modules compiled into the shipped `sm-agent` binary (`CGO_ENABLED=0`, `linux/amd64` and `linux/arm64`;
`prometheus/procfs` is Linux-only, so `darwin/arm64` builds 31 of these 32). Each licence was read from the module's own
`LICENSE` file at the version named (plan 015 T1.4; the audit that cleared all 32 is `docs/tasks/licence-audit-2026-09.md`
on the backend branch, addendum C.3; that file is not on this branch, so the reference dangles until the backend PR merges). The Go standard library is statically linked: BSD-3-Clause.

`scripts/check-licences.sh` fails when `go list -deps ./cmd/sm-agent` (minus the main module) names a module or version
that is not a row of the table below. **Keep the table to one row per line, `| module | version | licence |`.**
The licence texts at the end of this file (the module section between the `GENERATED` markers) are produced by `scripts/gen-licence-texts.sh`, and
`scripts/check-licences.sh` fails when they are stale or when a compiled-in module has no licence text. The attribution notices
required by Apache-2.0 section 4(d) are in `NOTICE` (`scripts/gen-notice.sh`). Both files are copied into the image at `/usr/share/doc/sm-agent/`.

Dev tools (not shipped): the shipped image builds with `golang:1.26.4` (`Dockerfile`, `go.mod` says 1.26.4); Go 1.27.1 is only the
local evidence toolchain this table was measured with; `buf` 1.73.0 is the pinned generation tool
(Apache-2.0); `protoc-gen-go` v1.36.12 (BSD-3-Clause); `protoc-gen-go-grpc` v1.5.1 (Apache-2.0).
